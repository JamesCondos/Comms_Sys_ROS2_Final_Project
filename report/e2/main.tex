\title{Queueing Relationships and Arrival Variability:\\A Shared ROS~2--REST Gateway}
\author{ELEN90061 Communication Networks}
\date{E2 experimental report}
\begin{document}
\maketitle
\begin{abstract}
A 20-run discrete-event M/M/1 calibration was followed by 20 measured ROS 2--HTTP runs with four actual source nodes and four arrival patterns. The model mean-delay differences from configured-rate theory were 0.15--1.67\%. The live study held the expected load at 128 messages/s with one shared FIFO sender and a fixed 4.0 ms server hold. Condition-mean gateway p95 residence ranged from 5.79 to 446.03 ms. There were 0 FIFO drops in the measured source cohorts. Exact finite-window population accounting separates the queueing relationship from assumptions about arrival and service distributions. Model durations are simulated; the arrival-pattern results are measured on an isolated virtual network on one host.
\end{abstract}
